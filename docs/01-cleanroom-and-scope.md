# 清洁室与素材范围

## 实现原则

Kaze 的引擎适配依据公开引擎文档、公开协议和自行生成的测试数据完成。仓库不收录同类产品的可执行文件、反编译结果、资源包、界面素材或会员数据。

引擎行为的知识来源登记在根目录 `SOURCES.md`。新增引擎行为时，应先确认其公开来源，再实现和添加测试。

## 可以入库

- 项目自身源码、协议定义和构建脚本；
- 用户向 README、当前架构与构建文档；
- 项目自行绘制的图标；
- `tools/make_rgss_fixtures.py` 生成的虚构 RGSS 测试夹具；
- 不指向真实用户、真实游戏目录或真实账号的测试数据。

## 不入库

- 商业游戏文件、存档、截图、封面原图和第三方 UI 素材；
- API Key、令牌、私钥、用户配置、游戏库路径和会话文件；
- 日志、诊断包、数据库备份、游戏原文备份和存档 ZIP；
- 本地模型、推理运行时、编译产物和下载的工具链。

详细检查规则见 `docs/COMPLIANCE.md`，发布前运行 `python tools/check_public_repo.py`。
