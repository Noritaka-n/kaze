# 当前功能对照

本文只描述 Kaze 当前实现，不包含竞品对照或历史计划。

| 功能 | RPG Maker MZ / MV | RPG Maker XP / VX / VX Ace |
| --- | --- | --- |
| 游戏目录识别 | 支持 | 支持 |
| 本地封面与启动 | 支持 | 支持 |
| 离线文本扫描 | 支持，读取数据 JSON | 支持，读取 RGSS 数据 |
| 翻译写回 | 支持 | UTF-8 / RGSS3 支持；未标记的旧编码数据只读 |
| 翻译记忆 | SQLite、模糊复用、CSV 导入导出 | 同左 |
| 术语表 | 支持 | 支持 |
| 开关与变量 | 支持 | 通过内存扫描与写入处理数值 |
| 货币、道具、队伍 | 支持专用面板 | 使用通用内存修改面板 |
| 穿墙、遇敌、传送 | 支持 | 不提供语义面板 |
| 地图与事件 | 支持地图信息、事件列表与定位 | 不提供语义面板 |
| 修改速度 | 支持运行时倍速操作 | 未提供专用面板 |
| 存档备份与还原 | 支持 | 未提供专用面板 |

## 通用能力

- 深色桌面界面、游戏搜索与目录扫描；
- 用户自备 OpenAI 兼容翻译 API；
- 设置与 API Key 保存在本机，密钥使用 DPAPI 加密；
- 只读模式阻止文本写回和还原；
- relay 协议自检、适配器离线测试和 Kotlin 单元测试。

## 范围说明

Unity、Godot、KiriKiri、Wolf 等引擎不在当前支持范围。`adapters/renpy/` 是保留的历史实验代码，不代表当前版本支持 Ren'Py。
